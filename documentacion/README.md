# Documentación de Acceso Seguro

Repositorio oficial de documentación del plugin WordPress **Acceso Seguro**.

La documentación se organiza en distintos niveles según el perfil de la persona que la consulte.

## Estructura de la documentación

### Usuario

Documentación orientada a administradores de WordPress y usuarios finales del plugin.

Contenido:

* Instalación
* Primeros pasos
* Configuración general
* Sistema antispam
* Gestión de logs
* Preguntas frecuentes

Ruta:

```text
documentacion/usuario/
```

### Funcional

Describe el comportamiento funcional del plugin desde el punto de vista de sus características y pantallas de administración.

Contenido principal:

* Panel de ajustes
* Configuración general
* Seguridad
* Sistema de puntuación
* Reglas de email
* Reglas de username
* Logs
* Visor de logs
* Personalización del popup

Ruta:

```text
documentacion/funcional/
```

### Técnico

Documentación orientada a desarrolladores y mantenimiento técnico.

Contenido principal:

* Arquitectura general
* Sistema antispam
* Rate limiting
* Bloqueo progresivo
* Señales antispam
* Almacenamiento y base de datos
* Sistema de logs
* Endpoints AJAX
* Sistema de configuración

Ruta:

```text
documentacion/tecnico/
```

### Desarrollo

Documentación relacionada con la evolución interna del proyecto.

Objetivos:

* Procedimientos de desarrollo
* Convenciones de código
* Flujo Git
* Procesos de despliegue
* Tareas pendientes
* Roadmap técnico

Ruta:

```text
documentacion/desarrollo/
```

### Versiones

Histórico de cambios y evolución del plugin.

Objetivos:

