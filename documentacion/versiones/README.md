# Versiones de Acceso Seguro

## Objetivo

Esta sección recopila la evolución histórica del plugin Acceso Seguro.

Su finalidad es documentar los cambios realizados entre versiones y facilitar el seguimiento del desarrollo del proyecto.

## Estructura

Cada versión estable del plugin dispondrá de su propia documentación de cambios.

Ejemplo:

```text
versiones/

README.md

v1.0.0.md
v1.1.0.md
v1.2.0.md

...
```

## Información que debe registrarse

Para cada versión se recomienda documentar:

### Nuevas funcionalidades

Características incorporadas al plugin.

### Mejoras

Cambios que mejoran funcionalidades existentes.

### Correcciones

Errores corregidos respecto a versiones anteriores.

### Cambios internos

Modificaciones técnicas que no afectan directamente al usuario final.

### Compatibilidad

Cambios relacionados con:

* WordPress
* PHP
* Integraciones
* Dependencias

## Roadmap

Además de las versiones publicadas, esta carpeta podrá utilizarse para documentar:

* funcionalidades planificadas
* cambios pendientes
* hitos del proyecto
* evolución prevista del plugin

## Estado actual

Actualmente la documentación histórica de versiones todavía no se ha generado.

La creación de archivos de versión comenzará cuando se publique la primera versión estable documentada del plugin.
