# Versión 1.0.0

Fecha: 2026-06-16

## Estado de la versión

Primera versión estable documentada de Acceso Seguro.

Esta versión se encuentra funcionando en producción en una tienda online real y ha demostrado ser eficaz para bloquear registros automatizados y usuarios spam sin incidencias reportadas por los usuarios legítimos.

## Objetivo principal

Reducir y eliminar el registro automático de usuarios spam en WordPress mediante un sistema antispam multicapa integrado con los procesos nativos de autenticación.

## Funcionalidades incluidas

### Protección de login

Protección del proceso de inicio de sesión mediante:

* Rate limiting
* Sistema de puntuación
* Bloqueo progresivo
* Registro de eventos

### Protección de registro

Protección del formulario de registro mediante:

* Validación de email
* Validación de username
* Sistema de puntuación
* Bloqueo progresivo
* Registro de eventos

### Recuperación de contraseña

Protección del proceso de recuperación mediante:

* Rate limiting
* Registro de eventos

## Sistema antispam

Implementación de un sistema multicapa basado en:

### Rate limiting

Configuración inicial:

* Login: 8 intentos / 300 segundos
* Registro: 4 intentos / 900 segundos
* Recuperación: 4 intentos / 900 segundos

### Sistema de puntuación

Evaluación de riesgo mediante señales acumulativas.

Configuración inicial:

* Umbral dinámico: 8
* Umbral de bloqueo: 70

### Bloqueo progresivo

Configuración inicial:

* 5 minutos
* 30 minutos
* 120 minutos
* 1440 minutos

### Señales de email

Incluye:

* Comprobación MX
* Dominios bloqueados
* TLDs bloqueados

TLDs iniciales:

* xyz
* top
* zip
* mov

### Señales de username

Incluye:

* Longitud mínima
* Ratio de vocales
* Rachas de consonantes
* Patrones sospechosos

## Sistema de logs

Implementación de:

* Registro de eventos
* Visor de logs
* Vista detallada
* Exportación CSV
* Eliminación de registros
* Hash de IP para privacidad

## Panel de administración

Incluye:

* Configuración general
* Seguridad
* Sistema de puntuación
* Reglas de email
* Reglas de username
* Configuración visual del popup
* Gestión de logs

## Personalización visual

Sistema de personalización del popup mediante configuración administrativa:

* Colores
* Tipografía
* Bordes
* Espaciados
* Dimensiones

Sin necesidad de CSS personalizado.

### WordPress

Compatible con instalaciones modernas de WordPress basadas en el sistema estándar de usuarios.

Compatible con la versión mínima definida por el plugin.

## Resultados observados

Durante su uso en producción:

* Eliminación práctica del registro automatizado de usuarios spam.
* Ausencia de incidencias reportadas relacionadas con usuarios legítimos bloqueados.
* Funcionamiento estable durante varios meses.
