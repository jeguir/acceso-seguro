# Manual de usuario

## Introducción

Acceso Seguro es un plugin para WordPress diseñado para proteger los procesos de acceso y registro frente a spam, automatizaciones y abusos.

A diferencia de otros sistemas, Acceso Seguro utiliza mecanismos internos de validación y análisis de riesgo para detectar comportamientos sospechosos sin depender necesariamente de CAPTCHAs tradicionales.

## ¿Qué puede hacer Acceso Seguro?

Entre sus principales funcionalidades se encuentran:

* Protección de formularios de acceso.
* Protección de registros de usuarios.
* Protección de recuperación de contraseña.
* Limitación de intentos (rate limiting).
* Sistema de puntuación basado en señales.
* Bloqueo progresivo por reincidencia.
* Registro de eventos y actividad sospechosa.
* Herramientas de análisis mediante visor de logs.

## Requisitos

Acceso Seguro requiere:

* WordPress actualizado.
* Permisos de administrador para la configuración.
* PHP compatible con la versión mínima soportada por el plugin.
