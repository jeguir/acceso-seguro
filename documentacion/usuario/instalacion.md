# Instalación

## Introducción

Acceso Seguro se instala como cualquier otro plugin de WordPress.

Una vez activado, el plugin añade nuevas opciones de configuración en el área de administración y comienza a proteger los procesos de acceso y registro según la configuración establecida.

## Instalación desde archivo ZIP

### Paso 1. Acceder al área de plugins

Desde el panel de administración de WordPress:

```text
Plugins → Añadir nuevo plugin
```

### Paso 2. Subir el plugin

Seleccionar:

```text
Subir plugin
```

y elegir el archivo ZIP de Acceso Seguro.

### Paso 3. Instalar

Pulsar:

```text
Instalar ahora
```

y esperar a que WordPress complete la instalación.

### Paso 4. Activar

Una vez finalizada la instalación, pulsar:

```text
Activar plugin
```

## Verificación inicial

Tras la activación, Acceso Seguro añadirá nuevas opciones en el área de administración.

Se recomienda comprobar que:

* El plugin aparece como activo.
* El menú de Acceso Seguro es accesible.
* No se muestran errores de activación.
* La configuración puede guardarse correctamente.

## Configuración inicial recomendada

Después de instalar el plugin se recomienda:

1. Activar la protección principal.
2. Activar la limitación de intentos.
3. Activar el sistema de puntuación.
4. Activar el bloqueo progresivo.
5. Revisar las reglas de email.
6. Revisar las reglas de username.
7. Activar el sistema de logs.

La configuración detallada se explica en:

```text
primeros-pasos.md
```

## Actualización del plugin

Las nuevas versiones pueden instalarse siguiendo el mismo procedimiento utilizado para la instalación inicial.

Antes de actualizar se recomienda:

* Realizar una copia de seguridad.
* Revisar las notas de la versión.
* Verificar la compatibilidad con la versión de WordPress utilizada.

## Desinstalación

Para desinstalar el plugin:

```text
Plugins → Plugins instalados
```

Localizar Acceso Seguro y seleccionar:

```text
Desactivar
```

Posteriormente:

```text
Eliminar
```

## Recomendaciones

Tras cualquier instalación o actualización importante se recomienda:

* Verificar el acceso al sitio.
* Comprobar el funcionamiento del login.
* Comprobar el funcionamiento del registro de usuarios.
* Revisar los logs durante los primeros días de uso.
* Confirmar que las reglas antispam funcionan según lo esperado.
