# Estilos del popup

## Objetivo

La sección Estilos del popup permite personalizar la apariencia visual del modal de acceso de Acceso Seguro desde el panel de administración.

Estos ajustes se aplican mediante variables CSS, sin necesidad de escribir código CSS manualmente.

## Opciones disponibles

### Ancho máximo

Permite definir el ancho máximo del popup en píxeles.

Rango identificado:

```text
280 - 720 px
```

### Padding interno

Permite definir el espacio interior del popup.

Rango identificado:

```text
0 - 48 px
```

### Radio de borde

Permite definir el redondeo de las esquinas del popup.

Rango identificado:

```text
0 - 40 px
```

### Opacidad del fondo

Permite definir la opacidad del fondo superpuesto detrás del popup.

Rango identificado:

```text
0 - 0.9
```

### Color principal

Permite definir el color principal utilizado por el popup.

### Color de títulos

Permite definir el color de los títulos del modal.

### Fondo de inputs

Permite definir el color de fondo de los campos del formulario.

### Color del borde de inputs

Permite definir el color del borde de los campos del formulario.

### Grosor del borde de inputs

Permite definir el grosor del borde de los campos del formulario en píxeles.

Rango identificado:

```text
0 - 6 px
```

El valor `0` equivale a campos sin borde.

### Color de fondo

Permite definir el color de fondo del popup.

### Color de texto

Permite definir el color principal del texto del popup.

## Restablecer colores del modal

La sección incluye una acción para restablecer los colores del modal.

Durante la auditoría se ha identificado un botón específico para esta función:

```text
Restablecer colores del modal
```

## Consideraciones

Los ajustes de esta sección afectan a la apariencia del popup, pero no modifican la lógica funcional del sistema de acceso, registro o recuperación de contraseña.
