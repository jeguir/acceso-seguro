# Acceso Seguro

Plugin WordPress para login y registro AJAX con protección antispam avanzada basada en heurísticas reales, rate limiting y bloqueo progresivo.

Compatible con WordPress y WooCommerce.

## Características principales

* Protección antispam sin CAPTCHA.
* Sistema de puntuación basado en señales.
* Rate limiting configurable.
* Bloqueo progresivo por reincidencia.
* Reglas avanzadas para email.
* Reglas avanzadas para nombre de usuario.
* Registro de eventos y visor de logs.
* Exportación de logs en CSV.
* Personalización visual del popup.
* Integración con WooCommerce.

## Instalación

1. Descarga la última versión desde la sección **Releases**.
2. En WordPress ve a **Plugins → Añadir plugin → Subir plugin**.
3. Selecciona el archivo ZIP descargado.
4. Activa el plugin.
5. Configura las opciones desde el panel de administración.
